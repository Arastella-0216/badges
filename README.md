# badges

[`Arastella-0216/matching-scent`](https://github.com/Arastella-0216/matching-scent) README 의 배포 상태 배지용 [shields.io endpoint](https://shields.io/badges/endpoint-badge) 데이터.

- `production.json` — 최신 정식 릴리즈 버전·배포일
- `staging.json` — 최신 staging 배포일

## 운영

- **자동 갱신됨.** matching-scent 의 배포 워크플로(`release.yml`, `cd-staging-backend.yml`, `cd-staging-frontend.yml`)가 배포 성공 시 이 파일들을 덮어쓴다.
- **직접 편집하지 말 것** — 다음 배포에서 덮어써진다.

## 왜 이 레포가 공개인가

`matching-scent` 는 private 이라 shields.io 가 릴리즈 정보를 익명으로 읽을 수 없다. 그래서 배지 값(버전 문자열·날짜)만 이 **공개** 레포로 분리한다. 코드·저장소 구조는 노출되지 않는다.
